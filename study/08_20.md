# Composerについて

Composerとは、PHPのパッケージ管理ツール

---

## ４つのメリット

### ① インストール／アップデート／アンインストールをコマンド１つで実行できる
`composer.json`、`composer.lock`により、バージョン管理や依存関係を自動で解決してくれる

### ② アプリ単位でパッケージを管理できる
アプリにおけるパッケージは、アプリごとに特定のバージョンに依存している場合も多々ある
composerでは、過去のパッケージ管理ツールである`PEAR`とは異なり、アプリごとにパッケージを管理できる

### ③ 自動ローディング機能
ライブラリ使用時に、いちいち個別にインポートせず、自動で有効化できる

### ④ パッケージの数が豊富
[Composerパッケージリスト](https://packagist.org/)

---

## セマンティックバージョニングとは

Composerではセマンティックバージョニングというルールでバージョン管理してる

バージョンは`「メジャー . マイナー . パッチ」`で構成され、以下の特徴がある

**メジャー：** 互換性が保たれない破壊的な変更
**マイナー：** 機能追加あり、互換性維持
**パッチ：** バグフィックスなどの変更、機能追加は無し

### バージョン表記

|表記|意味|
|:---|:---|
|~1.2.5|1.2.5以上　1.3.0未満|
|^1.2.0|1.2.0以上　2.0.0未満|
|1.2.* |1.2.0以上　1.3.0未満|
|*|現在の最新バージョン|

## ディレクトリ構造

```bash
/my-app
    ├── composer.json    # パッケージ定義
    ├── composer.lock    # パッケージ情報
    └── /vendor          # ライブラリの動作に必要なファイル一式
        ├── /composer    # Composer共通
        ├── {パッケージ}  # 特定のパッケージフォルダ
        ├── /psr         # HTTP関連の標準インターフェイス
        ├── /ralouphie   # 下位互換性のためのライブラリ
        └── autoload.php # ライブラリを自動ロードするためのファイル
```

## composer.jsonとcomposer.lockについて

### composer.json

`composer require {ライブラリ名} {バージョン}`でライブラリをインストールすると
このファイルの`require（要求）キー`配下にパッケージの情報が記録される
```json
{
  "require": {
    "guzzlehttp/guzzle": "~7.3.0"
  }
}
```

これは手書きで編集することも可能で、編集後に`composer update`を実行すると
`composer.json`の記述に沿ってライブラリを更新（追加）できる

逆に、不要なライブラリの記述を削除して`composer update`を実行すると、削除
することもできる

> composer installを実行することで、異なるコンピューターに
> 同じパッケージ環境を再現する上でも役立つ

### composer.lock

インストールのタイミングでcomposerが自動生成するファイル（手書きは基本しない）

実際にインストールされたライブラリをバージョンも厳格に記述される

> composer installはlock優先で読み込む（環境をより忠実に再現可能）
> updateはjson優先で読み込む

## 主なcomposerコマンド

```bash
composer require {パッケージ} {バージョン} # 特定のパッケージ取得
composer require --dev {パッケージ} {バージョン} # 特定のパッケージを開発環境向け取得

composer install # lock優先でパッケージ群をインストール
composer update # json優先でパッケージ群を追加・削除

composer self-update # composer自身を更新

composer validate # composer.jsonの記述検証

composer search {パッケージ} # ライブラリ情報を取得

composer show -i # インストール済みパッケージ情報を表示
composer show -p # PHP拡張機能の情報を表示
composer show {パッケージ} # パッケージの情報を取得
```

### 開発環境向けのインストール

`--dev`オプションで`composer.json`には以下のような記述になる

```json
{
  "require": {
    "guzzlehttp/guzzle": "7.2.0",
    "ezyang/htmlpurifier": "*"
  },
  "require-dev": { // これ！
    "phpunit/phpunit": "^9.5"
  }
}
```

開発者向けのライブラリとして指定され、以下のコマンドで除外できる

```bash
composer install --no-dev
```
